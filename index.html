PART D: INTERVIEWER'S QUESTION

Your lecturer may select any group member to answer ONE interview-style question related to the group's case study. Be prepared to explain your reasoning and justify your proposed solution.

Example questions:

  • How would you troubleshoot a network connectivity problem?
  • Why might an organization use VLANs and ACLs together?
  • How would you improve network reliability if one network link failed?
  • What would you investigate if a cloud application became unreachable?
  • Why is network automation useful in modern organizations?
